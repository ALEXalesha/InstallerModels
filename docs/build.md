# Сборка exe

## Что нужно

| Инструмент | Зачем | Проверить |
|---|---|---|
| Python 3.8+ | сам код | `python --version` |
| PyInstaller | превращает скрипт в exe | `python -m PyInstaller --version` |
| NSIS 3 | собирает установщик | `"C:\Program Files (x86)\NSIS\makensis.exe" /VERSION` |
| Pillow | только чтобы перерисовать иконку | `python -c "import PIL"` |

Если PyInstaller не стоит:

```bash
python -m pip install pyinstaller
```

NSIS ставится с https://nsis.sourceforge.io. Без него portable-версия всё равно соберётся, установщик просто пропустится с предупреждением.

## Сборка

```bash
python build.py
```

Скрипт чистит `build/` и `dist/`, потом делает три вещи.

Portable: PyInstaller в режиме `--onefile`. Получается один exe около 11 МБ, всё внутри. Запускается примерно за 1.8 секунды, потому что при каждом старте распаковывает себя во временную папку.

Папка приложения: PyInstaller в режиме `--onedir`, около 26 МБ. Стартует за 0.6 секунды, потому что распаковывать нечего. Это то, что кладётся в установщик.

Установщик: NSIS собирает содержимое `dist/app/InstallerModels` в один exe примерно на 8.5 МБ.

Результат:

```
dist/portable/InstallerModels.exe        11.3 МБ
dist/app/InstallerModels/                26.2 МБ
dist/InstallerModels-Setup-1.0.0.exe      8.5 МБ
```

## setup.nsi обязан быть в UTF-8 с BOM

Это не придирка, а грабли, на которые я наступил. В режиме `Unicode true` makensis определяет кодировку файла по BOM. Если BOM нет, он читает `.nsi` как ANSI в системной кодировке и молча портит всю кириллицу. Ошибок при сборке не будет, установщик соберётся, но:

- надписи в окне установщика превратятся в мусор,
- имя ярлыка «Удалить InstallerModels» будет нечитаемым,
- строка `WINTITLE` испортится, и проверка запущенной программы перестанет находить окно.

Последнее самое неприятное: деинсталлятор при этом сносит ярлыки, реестр и все незалоченные файлы прямо под работающей программой, оставляя огрызок из загруженных в память DLL.

`build.py` проверяет BOM перед вызовом NSIS и падает с внятной ошибкой, если его нет. Если правишь `setup.nsi` редактором, который сохраняет UTF-8 без BOM, вернуть его можно так:

```bash
python -c "p='setup.nsi';d=open(p,'rb').read();open(p,'wb').write(d if d[:3]==b'\xef\xbb\xbf' else b'\xef\xbb\xbf'+d)"
```

## Защита от запущенной программы

Установщик и деинсталлятор ищут окно программы через `FindWindow` по заголовку и отказываются работать, если оно найдено. Заголовок задан дважды: в `gui.py` в `window.title()` и в `setup.nsi` в `WINTITLE`. Меняешь один - меняй второй, иначе проверка тихо перестанет срабатывать.

Сначала я делал эту проверку через попытку открыть exe на запись, рассчитывая на то, что Windows держит запущенный файл заблокированным. В установщике это работало, в деинсталляторе нет: он запускается копией из `%TEMP%` и видит другой `$INSTDIR`. Поиск окна от расположения не зависит и работает в обоих.

## Почему tkinter

Окно написано на tkinter, потому что он входит в стандартную библиотеку Python. PyInstaller кладёт в exe только Tk, и получается 11 МБ. На PySide6 или PyQt тот же экран весил бы 60-80 МБ.

## Версия

Версия задана в `build.py` переменной `VERSION` и передаётся в NSIS ключом `/DVERSION`. Поменял там - поменялось и имя файла установщика, и запись в «Программы и компоненты».

Собрать установщик отдельно, без PyInstaller (папка `dist/app` уже должна быть на месте):

```bash
"C:\Program Files (x86)\NSIS\makensis.exe" /DVERSION=1.0.0 setup.nsi
```

## Иконка

`icon.ico` собрана скриптом на Pillow и содержит размеры от 16 до 256 пикселей. Перерисовать её можно чем угодно, лишь бы файл остался многоразмерным `.ico` - иначе Windows будет мылить иконку в панели задач.

Иконка попадает в три места: внутрь exe как ресурс, в окно программы через `iconbitmap`, и в установщик как `MUI_ICON`. Ярлыки отдельного файла иконки не используют, они берут её прямо из exe.

## Что проверить после сборки

Portable запускается и показывает правильный путь к ComfyUI и свободное место.

Установщик ставится без запроса прав администратора.

После установки есть ярлык в Пуске и запись в «Программы и компоненты» с правильным размером.

Удаление через «Программы и компоненты» уносит папку, оба ярлыка и запись в реестре.

Тихая установка и удаление для быстрой проверки:

```bash
dist\InstallerModels-Setup-1.0.0.exe /S
```

```bash
"%LOCALAPPDATA%\Programs\InstallerModels\Uninstall.exe" /S
```

## Куда ставится

`%LOCALAPPDATA%\Programs\InstallerModels`, то есть в профиль пользователя. Поэтому не нужны права администратора и не выскакивает UAC. Обратная сторона: программа ставится только текущему пользователю, для другой учётной записи придётся поставить заново.
